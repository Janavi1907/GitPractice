# Weather App

## Project Description

A responsive weather application that fetches and displays weather information for a searched city using a weather API. It includes input handling and works across desktop and mobile devices.

## Features

- Search for weather information by city name
- Displays weather details for the searched city
- Fetches weather data using an API
- Handles invalid city searches and empty input
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML
- CSS
- JavaScript
- API
