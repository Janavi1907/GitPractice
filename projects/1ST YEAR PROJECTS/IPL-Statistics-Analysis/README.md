# IPL Statistics Analysis

## Project Description

A Python-based project to analyse IPL data and extract
useful statistics about teams and players.

## Objective

- Find which teams and players perform the best across IPL history.
- Measure how much winning the toss increases a team's chances of winning the match.
- Analyze how teams perform in specific cities (like   Mumbai or Bangalore).

## Dataset Information

The script processes a match logs file (Match_Info.csv) featuring details like teams, players, dates, locations, toss winners, toss decisions, and the match-day winner.

## Main Analyses Performed

- Team Comparison: Counts total wins and compares head-to-head toss-to-match win success for teams like CSK and MI.
- Player Awards: Counts who won the Player of the Match award the most times and lists the top 10 players.
- Toss Logic: Calculates the exact percentage of matches won by the team that won the toss.
- City Filter: Tracks match counts and team win rates in specific cities (e.g., Bangalore and Mumbai).

## Technologies

- Python
- Pandas
- CSV Dataset
