# Rock Paper Scissors Game

## Project Description

An interactive JavaScript game featuring player/computer choices,win/lose/draw detection, live score tracking, and a reset function.

## Features

- Choose Rock, Paper, or Scissors
- Random computer choice
- Win, lose, and draw results
- Scoreboard for the player, computer, and draws
- Reset button to restart the game scores

## Technologies Used

- HTML
- CSS
- JavaScript
