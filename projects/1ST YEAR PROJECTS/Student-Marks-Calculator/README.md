# Student Marks Calculator

## Project Description

A web application that calculates a student's total marks, average, percentage, and final result. It includes input validation to ensure that the required details and marks are entered correctly.

## Features

- Enter student name and USN
- Enter marks for five subjects
- Calculates total marks
- Calculates average marks and percentage
- Displays PASS or FAIL based on the marks
- Validates empty inputs and marks outside the allowed range

## Technologies Used

- HTML
- CSS
- JavaScript
