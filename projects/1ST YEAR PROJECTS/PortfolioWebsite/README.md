# Portfolio Website

## Project Description

A personal portfolio website designed to showcase my skills, projects, and learning journey as a Computer Science Engineering student. The website brings together my front-end development work in a clear and responsive design.

## Features

- About Me section introducing my learning journey
- Skills section showcasing the technologies I have learned
- Projects section displaying my completed projects
- Project descriptions and screenshots
- Links to explore my projects
- Responsive design for desktop and mobile devices
- Clean and organised user interface

## Technologies Used

- HTML
- CSS
